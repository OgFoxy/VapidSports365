# VapidSports365
Bot de apuestas deportivas

# 🎰  (Node.js)

Un bot de Discord que permite a los usuarios apostar monedas virtuales en eventos personalizados, gestionar su saldo y ver su historial. También incluye comandos administrativos para añadir o quitar saldo a otros usuarios.

## 🚀 Funcionalidades

- 💰 Economía virtual con saldo inicial
- 🎲 Apuestas con comandos slash (`/apostar`)
- 📊 Historial personal de apuestas
- 🛠️ Comando de administración para editar balances
- 🗃️ Base de datos local con SQLite

---

## 🛠️ Requisitos

- Node.js 18 o superior
- Una aplicación de bot de Discord con permisos de slash commands
